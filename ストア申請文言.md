## 概要 / Description（日本語）

```
LogSwapは、あなたのセットログを見せ合って交換する相手を見つけるアプリです。

スワイプして、おたがいが交換したいを選んだらログを交換。共通の趣味や記録でつながれます。出会い系ではなく、ログの交換に特化したシンプルなサービスです。

できること
- スワイプでかんたんに相手を探す
- おたがいOKで成立、そのままトーク
- プロフィール画像やログ動画で自分を表現
- ハッシュタグや地域でつながる

安心への配慮
- カメラやマイクは使用しません。写真や動画は端末に保存済みのものから選ぶだけです
- 不適切なコンテンツや迷惑行為は禁止。通報とブロックの機能があります
- 18歳以上の方が対象です
- アカウントと関連データはいつでも完全に削除できます

LogSwapプレミアム（任意）
- 月額サブスクで、トークできる人数が無制限などの特典
- 単発アイテムのブーストで交換されやすさアップ

まずは無料で始められます。
```

## 審査メモ（App Review Information の Notes 欄）

```
本アプリは「セットログ（記録）」を見せ合って交換する相手を見つけるサービスです。
出会い系・マッチングアプリではなく、ログ交換に特化しています。

・カメラ/マイクは使用しません（写真・動画は端末の保存済みから選択）。
・匿名アカウントが自動発行され、ログインなしで全機能を確認できます。
・アプリ内課金：LogSwapプレミアム（月額サブスク logswap_premium_month）と
  ブースト（単発 logswap_boost_30m）。
・アカウント削除はプロフィールタブの「アカウントを削除」から可能です。
・通報・ブロック機能を各プロフィールから利用できます。
・広告（Google AdMob）を表示します。ATT（App Tracking Transparency）の
  許可ダイアログは、初回起動時に約1秒後、ネイティブ側（AppDelegate）から
  自動で表示されます。ログイン等の操作は不要です。
・ATT の状態確認と再設定は、プロフィールタブ下部の「広告のトラッキング設定」
  からいつでも行えます（未回答ならここからダイアログを出せます）。
・位置情報は一切取得しません（位置情報のAPI呼び出しも権限もありません）。
```

## 審査メモ（英語版・リジェクト返信用）

5.1.2(i) のリジェクトに対する再提出時は、Notes をこれで丸ごと置き換える。
**build 12 以降はこちら**（自動表示のリトライ＋アプリ内の手動導線を追加したため）。

```
This build implements App Tracking Transparency.

1) AUTOMATIC PROMPT (first launch)
The ATT permission request is presented automatically about 1 second after the
app becomes active on the FIRST launch. It is requested from native code in
AppDelegate.applicationDidBecomeActive using
ATTrackingManager.requestTrackingAuthorization. No login, account creation, tap
or navigation is required. It appears on top of the very first screen.
If iOS does not present the dialog on that attempt, the app retries on the next
few activations.

2) MANUAL ENTRY POINT (always reachable)
Because iOS shows the system dialog only once per install, this build also has a
permanent in-app control:

    Profile tab (bottom right)  ->  scroll down  ->  "Ad tracking"

The card shows the current tracking status ("Not set" / "Allowed" /
"Not allowed" / "Restricted"). When the status is "Not set", the button
"Ask for tracking permission" presents the ATT system dialog. When the user has
already answered, the button opens iOS Settings instead, because iOS does not
allow an app to ask twice.

IF YOU DO NOT SEE THE DIALOG, PLEASE CHECK:
- The prompt is shown only once per install. If the app from a previous review
  round is still on the device, please DELETE the app and reinstall it.
- Settings > Privacy & Security > Tracking > "Allow Apps to Request to Track"
  must be enabled on the test device. While that system switch is off, iOS
  suppresses the prompt for every app, and the in-app card will show
  "Restricted".

OTHER NOTES
- The AdMob SDK is initialized only after the user responds. If tracking is not
  allowed, the advertising identifier is not used and only non-personalized ads
  are served.
- The app does not use location services at all. There is no location API call
  and no location permission in the app. The App Privacy information has been
  corrected accordingly.
- The app behaves identically in all countries and regions.
- The Age Rating questionnaire answers "Yes" for Advertising.
```

## Resolution Center への返信（5.1.2(i)・英語）

```
Thank you for the review.

The app does track users on iOS, and this build (3.0, build 12) requests
permission through the App Tracking Transparency framework.

Where the permission request is located:
1. It is presented automatically about 1 second after the first launch, from
   native code in AppDelegate.applicationDidBecomeActive. Nothing needs to be
   tapped to reach it.
2. It can also be reached at any time from: Profile tab -> "Ad tracking" ->
   "Ask for tracking permission". This card also shows the current tracking
   status, so the implementation can be verified even after the dialog has
   already been answered on the device.

If the prompt did not appear during the previous review, it was most likely
because the system dialog is only presented once per install, or because
"Allow Apps to Request to Track" was turned off in Settings > Privacy &
Security > Tracking on the test device. Please delete any previously installed
copy of the app and confirm that this system setting is enabled.

We have also corrected the App Privacy information: the app makes no location
API calls and collects no location data, and crash and performance data are
used for app functionality and diagnostics only, not for tracking. The data
used for tracking is limited to the advertising identifier and advertising
data, which is only used after the user allows tracking.

The app behaves the same in all countries and regions.
```
