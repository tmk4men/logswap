## 概要 / Description（日本語）

```
LogSwapは、あなたのセットログを見せ合って交換する相手を見つけるアプリです。

スワイプして、おたがいが交換したいを選んだらログを交換。共通の趣味や記録でつながれます。出会い系ではなく、ログの交換に特化したシンプルなサービスです。

できること
- スワイプでかんたんに相手を探す
- おたがいOKで成立、そのままトーク
- プロフィール画像やログ動画で自分を表現
- ハッシュタグや地域でつながる

安心への配慮
- カメラやマイクは使用しません。写真や動画は端末に保存済みのものから選ぶだけです
- 不適切なコンテンツや迷惑行為は禁止。通報とブロックの機能があります
- 18歳以上の方が対象です
- アカウントと関連データはいつでも完全に削除できます

LogSwapプレミアム（任意）
- 月額サブスクで、トークできる人数が無制限などの特典
- 単発アイテムのブーストで交換されやすさアップ

まずは無料で始められます。
```

## 過去の経緯（ATT。2026-08-04 に方針転換）

5.1.2(i) で4回リジェクトされた。ATT はネイティブ（AppDelegate）実装・リトライ・
アプリ内の手動導線まで入れたが、審査端末に前回ビルドが残って回答済みになる／端末の
「Appからのトラッキング要求を許可」がOFF、のどちらでも審査員には何も見えず、
コード側から潰せなかった。そこでトラッキング自体をやめた。
再導入するなら、ATT は AdMob プラグイン経由ではなく自前のネイティブプラグインで出すこと。

## その他の設定メモ

- 年齢レーティング: **「広告」＝はい**（AdMobの広告を表示するため。2.3.6のリジェクト理由）
- 年齢レーティング: 18+（アプリ本体・利用規約・プライバシーポリシーが「18歳以上限定」で統一されているため、ストア側も揃える）
- カテゴリ: ソーシャルネットワーキング（またはライフスタイル）
- 著作権: `2026 tmk4men`

- ビルド: Xcode の Archive → Upload でアップロードしたものを選択（ブラウザからはアップ不可）
